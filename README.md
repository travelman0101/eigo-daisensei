# 英語大先生

好きな YouTube 動画の好きな区間を、すぐシャドーイング教材にして何度でも練習できる Web アプリ（日本語 UI・スマホ向け）。

- 本番: https://eigo-daisensei.ichi-apps.workers.dev
- 設計書: [docs/design.md](docs/design.md)
- 着手時の実証コード: [docs/spikes/caption-ai](docs/spikes/caption-ai)

## できること
- YouTube の URL を貼る → 題名・長さ・動画を表示 → 開始／終了を指定（直接入力・「今の位置を開始/終了に」・1/3/5/10 分間・試聴）
- 区間だけを AI で解析（文の区切り・意味のまとまり・日本語訳）。区間の端が文の途中なら広げる／狭める／このままを提案
- 練習: 聞く／リピーティング（止めて待つ）／シャドーイング（止めずに繰り返す）、意味のまとまり・一文・複数文、A–B ループ、区間全体、速度、反復回数、待ち時間（なし・秒数・聞いた長さ×倍率）、文末で自動停止、英語字幕・訳の表示切替、現在の文だけ／前後の字幕、文ごとの時刻補正、自己記録（まだ難しい／もう一度／できた）、録音して聞き比べ
- 単語・熟語（前後の語を足して 6 語まで）をタップ → 文脈の意味・品詞・原形・生成例文 → 単語帳へ。出典の場面に戻れる
- 単語テスト: カード（英→意味）・出典の文で穴埋め・例文で穴埋め。全部／復習時期／まちがえた語／教材別。簡単な間隔反復（5 段階）
- 端末に保存（IndexedDB、アカウントごとに分離）＋ Google ログイン時はクラウドにバックアップ・復元
- レベル別の見本（A1〜C1）はログインなしで試せる
- このアプリ自身に広告はありません（YouTube の広告はプレイヤー側で表示されることがあります）

## 技術の選定

| 項目 | 採用 | 理由 | 代替案と見送った理由 | 制限・料金 |
|---|---|---|---|---|
| 実行基盤 | Cloudflare Workers（Hono）＋静的ファイル配信 | 指定どおり Cloudflare 中心。API と画面を 1 本で配信でき、既存アプリ（Flick）と同じ構成で運用が簡単 | Pages Functions（機能は同等だが分ける利点がない） | 無料枠 1 日 10 万リクエスト |
| データベース | D1 | ユーザー・セッション・字幕/AI の共有キャッシュ・バックアップ・利用量の記録。SQL で所有者の絞り込みと冪等な更新が書きやすい | KV（結果整合で「処理中ロック」や上書き順の制御に向かない）、R2（カード登録が必要） | 無料枠 5GB・1 日 500 万行読み取り |
| 非同期処理 | 使わない（画面側が小さな API を順に呼ぶ） | 1 回の API が数秒で終わり、済んだ部分が即保存されるので、進行表示・キャンセル・再試行・画面移動が自然に成り立つ | Queues（サービスが増え、進行状況を別に通知する仕組みが必要） | — |
| AI | Workers AI `@cf/mistralai/mistral-small-3.1-24b-instruct` | 実測で速さ・費用・訳の質の均衡が最良（下表） | gpt-oss-120b（訳は最も自然だが 4 倍遅く 6 倍高い）、Llama 3.3 70B（訳が不自然）、Qwen3 30B（句読点の復元で単語を 1 つ落とした） | 無料枠 1 日 10,000 ニューロン。超過は 1,000 ニューロン $0.011 |
| 字幕の取得 | Supadata（外部 API、`mode=native`） | YouTube 公式の captions.download は動画の編集権限が必要で、任意の動画には使えない。Workers から YouTube を直接読むのは規約違反のうえ実測で失敗 | 字幕ファイルの読み込み・文字起こしの貼り付け（代替として実装） | 無料 100 回/月（カード不要）。1 動画 = 1 クレジット。AI 生成字幕（`generate`）は使わない |
| 画面 | React 19 + Vite + Motion | 既存アプリと同じ。Motion で滑らかな遷移、OS の「動きを減らす」に従う | — | — |
| 端末保存 | IndexedDB（idb） | 大きな教材を構造のまま保存でき、オフラインでも読める | localStorage（容量 5MB 程度で足りない） | ブラウザの容量制限・消去の影響を受ける |
| 認証 | Google OAuth（arctic）＋ HttpOnly Cookie セッション | 指定どおり Google のみ。セッションは D1 にハッシュで保存 | — | Google Cloud の OAuth 同意画面が「テスト中」の間はテストユーザーだけ |
| テスト | Vitest（Workers 実行環境）・Playwright | API は本物の Workers ランタイムと D1 で、画面はスマホ幅の Chromium で確認 | — | — |

### AI モデルの実測（2026-10-23、Workers 上、130 語の話し言葉）
| モデル | 句読点の復元 | 訳＋まとまり（5 文） |
|---|---|---|
| Mistral Small 3.1 24B | 3.3 秒・15 ニューロン・単語一致 | 5.3 秒・23 ニューロン・訳は自然 |
| Llama 3.3 70B fast | 2〜4 秒・40 ニューロン・単語一致 | 8.7 秒・65 ニューロン・訳が不自然 |
| Qwen3 30B | 1.8 秒・5 ニューロン・**単語が 1 つ欠落** | 2.7 秒・8 ニューロン・訳がやや不自然 |
| gpt-oss-120b | — | 20.7 秒・139 ニューロン・訳は最も自然 |
| gpt-oss-20b | 25 秒・74 ニューロン | 38.6 秒・80 ニューロン |

## 字幕の取得と制約
- YouTube Data API の captions.download は「動画を編集できる人」しか使えません（[公式](https://developers.google.com/youtube/data/reference/rest/v3/captions/download)）。
- Workers から YouTube のページを直接読む方法を実測: 字幕の一覧は見えても中身は空（200・0 バイト）、2 本目で 429。YouTube の規約は自動化された手段でのアクセスを禁止しているため不採用（[規約](https://www.youtube.com/static?template=terms)）。
- Supadata を使う判断は本人が規約リスクを理解したうえで選択しました。Supadata の規約は「各プラットフォーム規約の順守は利用者の責任」としています（[規約](https://supadata.ai/terms)・[料金](https://supadata.ai/pricing)）。
- 字幕は全体を 1 回だけ取得します（Supadata が全体しか返さないため）。AI に渡すのは選んだ区間（＋文の境界を決めるため前後約 1 分ずつ、句読点の復元のみ）だけです。
- 字幕が取れない動画（字幕なし・英語字幕なし・非公開・削除・Supadata の上限や障害）は理由を表示し、SRT/VTT の読み込みか YouTube の「文字起こし」の貼り付けで同じ動画に紐づけられます。これは代替手段です。
- 埋め込み禁止の動画はプレイヤーのエラー（101/150）で理由を表示します。

## 解析と時刻
- 約 60 秒ごとの「ブロック」に字幕を決定的に分け（50〜70 秒で最も間の長い切れ目）、ブロックごとに句読点を復元します。同じ字幕なら分け方は常に同じなので、重なる区間は済んだブロックを再利用します。
- AI は句読点と大文字だけを足し、単語は元の字幕のまま。1 語でも違えば 1 回やり直し、だめなら字幕の間（0.7 秒）と最大 20 語で機械的に区切ります。もともと句読点がある字幕は AI を使いません。
- 訳と意味のまとまりは文ごとにキャッシュ（D1）。重なる区間・再試行・連打で二重に推論しません。同時に来た同じ依頼は「処理中ロック」で 1 回にまとめます。
- 時刻は字幕の行の時刻です。行の途中で区切った文は文字数比の推定で、画面に「時刻は推定」と出します。AI に時刻は作らせません。ずれは文ごとに ±0.1 秒で補正して保存できます。
- 字幕の文言は AI への指示として扱いません（システム指示でデータと明示し、返答の形と単語列を検証）。

### 解析時間の上限: 1 教材 10 分
5 分の区間で約 320 ニューロン・待ち 20〜40 秒（実測予定値は下の「実測」参照）。10 分なら待ち 1 分前後で、反復練習の単位としても十分な長さのため。超えると「範囲を狭めるか分けて取り込む」と案内します。1 人 1 日の上限: 字幕取得 20 本、解析の AI 呼び出し 600 回（キャッシュ命中は数えない）、辞書 300 回（ログインなしは 1 IP 30 回）。

## 公式プレイヤーでできること・できないこと
| できる | できない／しない |
|---|---|
| 再生・停止・シーク・速度（YouTube が対応する段階）・文末での停止・反復 | バックグラウンド再生、音声だけの再生・抽出、音程を保った細かな速度変更 |
| 実測（PC の Chrome）: 再生位置の更新は約 6ms ごと、シークは 9〜56ms 手前に着地、自動停止は目標の 24〜36ms 手前 | YouTube の広告・必要な表示を消すこと |
| | スマホでの最初の再生の自動開始（ブラウザの制限。最初の 1 回は動画をタップ） |

## 保存と復元
- 端末: IndexedDB（`eigo:<ユーザーID>`、未ログインは `eigo:guest`）。共用端末でも別アカウントの単語帳・履歴は開きません。起動時に永続保存（`navigator.storage.persist()`）を要求。書き込み失敗・容量不足は「保存できませんでした」と表示します。
- 保存対象: 字幕（全体）、教材（区間・文・まとまり・時刻・訳・補正値・解析版）、練習状態、単語帳（辞書の結果・出典・覚えた度合い）、テスト結果、設定。動画本体は保存しません。
- バックアップ（ログイン時）: 教材・練習状態・単語帳・設定を D1 に保存（1 件 1MB・1 人 20MB まで、新しい方が勝つ）。変更から約 2.5 秒後にまとめて送信、失敗は 30 秒後と通信回復時に再送。端末が空なら起動時に自動復元（AI は呼びません）。テストの回答履歴は端末のみ。
- 削除: 設定画面から「JSON で書き出す」「この端末のデータを削除」「バックアップを削除」「アカウントを削除（D1 の全データ・セッション）」。ログアウトでは端末データは残ります。
- 字幕データの扱い: サーバーの共有キャッシュは重複取得防止のため 30 日で自動削除。本人の端末とバックアップの字幕は本人の学習用の写しです。無期限の保存は保証しません。
- 「再解析」は自動では行いません（解析版 `ANALYSIS_VERSION`・プロンプト版を記録）。

## AI 利用量と費用（記録の仕組み）
- すべての字幕取得・AI 呼び出しを D1 の `usage_log` に種類（字幕取得・文の区切り・訳・辞書）、モデル、ニューロン、時間、キャッシュ命中で記録し、設定画面に 30 日分を表示します。
- 取り込みごとの所要時間（字幕・区切り・訳）と AI 実行／再利用回数も教材に保存します。
- 想定: 1 日に 5 分の動画を 3 本取り込み、辞書を 50 回 → 約 320×3 + 約 30×50 ≒ 2,500 ニューロン/日（無料枠の 25%）。字幕は月 100 本まで無料。有料化は不要の見込み。

## セットアップ（開発）
```bash
npm install
cp .dev.vars.example .dev.vars   # DEV_AUTH / AI_MOCK / TRANSCRIPT_MOCK（ローカル専用）
npm run db:migrate:local
npm run dev
```
- ローカルは `/api/auth/dev-login?name=テスト` でログイン、AI と字幕は模擬データ。
- テスト: `npm run typecheck` / `npm test`（単体・API）/ `npm run e2e`（画面、毎回ローカル DB を作り直す）

```bash
npx wrangler d1 migrations apply eigo-daisensei --remote
npm run deploy
npx wrangler secret put SUPADATA_API_KEY
npx wrangler secret put GOOGLE_CLIENT_SECRET
```
Google OAuth のリダイレクト URI: `https://eigo-daisensei.ichi-apps.workers.dev/api/auth/callback`

## 練習の初期値（開発者の提案）
反復 3 回、待ち時間「聞いた長さ ×1.0」（聞いたのと同じだけ発話の時間をとるため）、前余白 0.15 秒・後余白 0.25 秒（推定時刻のずれで語頭・語尾が切れないため）。科学的な最適値や上達の保証ではありません。参考: [Oxford](https://teachingenglishwithoxford.oup.com/2013/01/23/shadowing-a-useful-technique-for-autonomous-practice-of-listening-and-speaking/)・[British Council](https://africa.teachingenglish.org.uk/classroom/pronunciation/shadowing)
