# 英語大先生 設計書（2026-10-23）

自分が選んだ YouTube 動画の好きな区間を、すぐシャドーイング教材にして何度でも練習する、日本語 UI・モバイルファーストの Web アプリ。
優先順位: ①取り込みの使いやすさ ②同期と反復操作 ③解析済み教材の保存・再利用 ④単語帳・テスト ⑤見本教材。

## 0. 着手時の実証（2026-10-23、Cloudflare 上の検証用 Worker で実測 → `docs/spikes/caption-ai`）
| 項目 | 結果 | 判断 |

## 1. 全体構成
- Cloudflare Workers（Hono）1 本で API と画面（React + Vite の静的ファイル）を配信。D1 にユーザー・セッション・字幕/AI の共有キャッシュ・バックアップ・利用量を保存。AI は Workers AI。
- Queues は使わない。解析は「画面側が小さな処理を順番に呼ぶ」方式にする。1 回の API は数秒で終わり、各結果はサーバーのキャッシュと端末に即保存される。→ 進行状況の表示・キャンセル（呼ぶのをやめるだけ）・再試行（済んだ部分はキャッシュで即返る）・別画面への移動が自然に成り立つ。
- 外部サービスは Supadata のみ（字幕取得）。

## 2. 取り込みの流れ
1. URL を貼る → 動画 ID と `t=` を正規化（youtu.be / watch / shorts / embed / live / m. / music. を許可。その他のホストは拒否）。
2. oEmbed で題名を即表示、公式埋め込みプレイヤーで動画時間を取得。埋め込み禁止（エラー 101/150）・削除（100）は理由を表示。
3. 字幕取得 `POST /api/transcript`。D1 の共有キャッシュ（動画 ID＋言語、30 日）にあれば即返す。なければ Supadata（`mode=native`＝AI 生成字幕は使わない。1 回 = 1 クレジット）。202（非同期ジョブ）はサーバーで最大 20 秒待ち、まだなら画面側が続きを問い合わせる。全字幕を 1 回で取るが、AI に渡すのは選択区間だけ。
4. 区間指定: 開始・終了の直接入力（`5:00` `1:02:03` `300`）、「今の位置を開始/終了に」、5 分/10 分プリセット（開始位置＋長さ）、試聴、区間の長さと全体の長さを表示。逆転・範囲外・空区間・上限超えを検証。
5. 句読点の復元（下の 3 章）を区間にかかる「ブロック」だけ実行 → 区間の端が文の途中なら「04:57.3（文の始まり）に合わせますか？」と提案。黙って広げない。「このまま」を選ぶと、端の文は「区間外を含む文」として薄く表示し、区間全体の再生は指定どおりの時刻で止まる。
6. 区間内の文だけ訳＋意味のまとまりを生成 → 教材として端末に保存し、すぐ練習画面へ。
- 解析時間の上限: 1 教材 10 分（600 秒）。理由: 実測で 5 分 ≒ 約 320 ニューロン・待ち 20〜40 秒。10 分なら 1 分前後の待ちで、反復練習の単位としても十分長い。超えたら「範囲を狭めてください（例: 10 分ごとに分けて取り込む）」と案内。
- 字幕が取れない動画（字幕なし・Supadata 障害・上限）: 理由を短く表示し、SRT/VTT ファイル読み込み、または YouTube の「文字起こし」をコピーして貼り付ける導線へ。これらは代替であり「URL から自動教材化」とは別に報告する。

## 3. 解析（AI）と時刻
- ブロック: 字幕全体を約 60 秒ごとのブロックに決定的に分ける（50〜70 秒の範囲で最も間が長い字幕の切れ目）。同じ字幕なら常に同じ分け方になるので、重なる区間は済んだブロックを再利用できる。
- 句読点の復元（1 ブロック 1 回）: 単語列を渡し、句読点と大文字だけを足させる。返答を正規化して元の単語列と 1 語でも違えば 1 回だけやり直し、それでもだめなら字幕の間（0.7 秒以上）と最大 20 語で機械的に区切る。単語は常に元字幕のものを使い、AI は区切り位置だけを決める。
- 文がブロックをまたぐ場合（末尾が . ? ! で終わらない）は次のブロックの最初の文とつなぐ。
- 訳＋まとまり（最大 8 文ずつ）: 文ごとのキャッシュ（文の原文＋プロンプト版＋モデル）なので、重なる区間・再試行・連打で二重に推論しない。返答のまとまりの単語列が原文と違えば、カンマと 5 語ごとの機械分割に切り替える。
- 時刻: Supadata は字幕行単位の開始・長さ（ミリ秒）を返す。文が行頭から始まるなら行の時刻（`timing: line`）、行の途中なら文字数比で配分した推定（`timing: estimated`）として保存し、画面にも「推定」と出す。AI に時刻は作らせない。
- 字幕の文言は AI への命令として扱わない（システム指示で「データ」と明示し、出力は JSON の形と単語列を検証）。
- AI 呼び出しはすべて D1 の `ai_usage` に種類（字幕取得・文分割・翻訳・辞書）・モデル・ニューロン・時間・キャッシュ命中を記録し、設定画面で見られる。
- 解析版: `ANALYSIS_VERSION`（プロンプトの版）を教材に保存。版が上がっても自動で再解析しない。「再解析」は設定から明示操作で、対象範囲と理由を表示し、成功してから差し替える。

## 4. 端末保存（IndexedDB）とバックアップ
- データベースはアカウントごとに別（`eigo:<ユーザーID>`、未ログインは `eigo:guest`）。共用端末で別アカウントの単語帳・履歴は開かない。
- 保存するもの: 字幕（全体）、教材（区間・文・まとまり・時刻・訳・補正値・解析版）、練習状態（位置・モード・自己記録）、単語帳、テスト結果、辞書の結果、設定。動画本体は保存しない。
- 初回に `navigator.storage.persist()` を要求。書き込み失敗・容量不足は「保存できませんでした」と表示し、黙って保存済みにしない。
- 教材 ID = 動画 ID＋字幕言語＋字幕のハッシュ＋区間（ミリ秒）。同じ URL・同じ区間なら既存の教材を開く（AI を呼ばない）。
- バックアップ（ログイン時のみ）: 端末の教材・単語帳・練習状態・テスト結果を D1 に保存（1 件 1MB、1 人 20MB まで）。変更後に数秒まとめて送る。端末が空でバックアップがあれば自動復元（AI 再推論なし）。同期失敗は表示して次回に再送。
- 削除・エクスポート: 設定画面に「JSON で書き出す」「この端末のデータを削除」「バックアップを削除」「アカウントを削除（D1 の全データとセッションを削除）」。ログアウトでは端末データは残すが、別アカウントからは見えない（DB が別）。
- 字幕の扱い: サーバーの共有キャッシュは重複取得を防ぐため 30 日で削除。教材として本人の端末とバックアップに残る字幕は本人の学習用の写し。見本教材はパブリックドメインまたは CC BY の動画だけを使い、出典と利用条件を表示する。無期限の保存は保証しない。

## 5. 練習プレイヤー
- 公式 YouTube IFrame Player。再生位置を 30ms 間隔で読んで現在の文・まとまりを強調。文をタップでその頭へ。
- 単位: 意味のまとまり / 一文 / 複数文（2〜5 文）。レベルと無関係に切り替え。
- モード: 聞く（通常再生）/ リピーティング（単位ごとに止めて待つ）/ シャドーイング（止めずに単位を N 回繰り返す、主モード）/ A–B ループ / 区間全体。
- 操作: 再生・停止、前/次の単位、同じ単位の頭へ、速度（0.5〜1.5）、反復回数（1〜10・無限）、待ち時間（なし / 固定 1〜10 秒 / 直前の長さ×0.5〜2）、文末で自動停止、英語字幕・訳の表示切替、現在の文だけ / 一覧表示。
- 練習の流れ（推奨の初期設定。いつでも飛ばせる）: 聞く → 意味を確認 → 区切ってまねる（リピーティング）→ 追いかけて話す（シャドーイング）→ 字幕なし。初回だけ短い説明を出す。段階のロックなし。
- 初期値と理由: 反復 3 回（同じ素材を短時間に繰り返す練習のため）、待ち時間「直前の長さ×1.0」（聞いた長さと同じだけ発話の時間をとるため）、前余白 0.15 秒・後余白 0.25 秒（推定時刻のずれで語頭・語尾が切れないため）。開発者の提案であり最適値ではない。
- 時刻の補正: 文ごとに開始/終了を ±0.1 秒で調整して保存。
- 自己記録: 文ごとに「まだ難しい / もう一度 / できた」。
- 自動保存: 最後の位置・モード・設定。再訪時は前回の文から 1 タップで再生。
- 公式プレイヤーの制約: バックグラウンド再生・音声だけの抽出・ピッチを保った速度の細かい制御・広告の非表示はしない/できない。モバイルは最初の再生にタップが必要。

## 6. 単語帳と単語テスト
- 字幕の単語をタップ（長押し/ドラッグで複数語＝熟語・句動詞）→ 動画を一時停止 → 辞書シート: 文脈での意味・品詞・原形・生成例文（英日）・「動画での発言」（実際の文）を区別して表示。閉じると元の文をすぐ再生できる。
- 辞書は必要時に AI で 1 回生成し、端末と D1 キャッシュ（語＋文）に保存。同じ語義の再表示で AI を呼ばない。
- 保存: 原形＋語義で重複を判定（同じ語の同じ意味はまとめて出典を追加、別の意味は別カード）。出典は動画・文・再生位置。
- テスト: 範囲（全部 / 教材別 / 間違えた語）。形式: カード（英→意味、答えを見て「覚えていた / 忘れていた」）、出典文の穴埋め入力、例文の穴埋め入力。正答・許容形は辞書生成時に保存し、採点は端末内（大文字小文字・前後の空白・連続空白・アポストロフィの種類を正規化）。
- 間隔反復: 5 段階の箱（0・1・3・7・14 日）。正解で 1 段上、不正解で 1 段目に戻し同じテストの最後にもう一度出す。
- 出典の場面を再生して復習できる。

## 7. 見本教材
- A1〜C1 各 3 本。パブリックドメイン（米国政府の著作物など）または CC BY の動画だけを使い、字幕の取得・埋め込み・同期を確認し、事前解析した JSON を同梱する。レベル・内容・全体の長さ・練習区間・判断理由（語彙・構文・話速 wpm・内容）を付け、「目安」であり公式判定ではないと表示。
- ログイン前に試せる。

## 8. 認証・安全
- Google ログインのみ（OAuth、セッションは HttpOnly Cookie、D1 にハッシュで保存）。ログイン前は見本教材の練習、辞書（IP あたり 1 日 30 回）、ゲスト単語帳が使える。自分の動画の取り込みはログイン後（字幕クレジットと AI 費用を守るため）。
- 1 日の上限（ユーザーごと）: 字幕取得 20 本、解析 60 分、辞書 300 回。入力上限（ブロック 400 語、文 8 件、語 60 文字、文 400 文字）。
- 同一オリジン以外からの書き込み拒否（CSRF）。バックアップは本人の行だけ読める。秘密は wrangler secret（Supadata キー・Google クライアントシークレット）。

## 9. 画面
ホーム（URL 入力・続きから・自分の教材・見本）/ 取り込み（動画＋区間指定＋進行状況）/ ライブラリ / 練習 / 単語帳とテスト / 設定。白ベースのガラス調（半透明・ぼかし・丸み）、文字は不透明に近い面の上に置いて読みやすさ優先。動きを減らす設定に対応。初回は全画面スケルトン、保存済み教材は即表示。

## 10. 第 2 段階（基礎の安定後）
- 録音して聞き比べ（使うときだけマイク許可、拒否しても練習は続けられる）。
- 「その単語が使われている別の動画」は取り込み済み教材の中だけで探す（YouTube 全体とは言わない）。
